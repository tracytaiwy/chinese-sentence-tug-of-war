# 四素句拔河大賽

小一中文雙人互動遊戲，學習「時間、人物、地點、事情」四素句。

- 左右玩家拖拉卡片，橫向排成句子。
- 答對一句，隊伍向己方拉繩；領先五分勝出。
- 輕快背景音樂、拔河人物動畫。
- 支援批量貼上及 TXT／TSV 題庫匯入、匯出與本機保存。

## 遊玩

用瀏覽器開啟 `index.html`，或使用本專案的 GitHub Pages 網址。

## 題庫格式

每行一題，以「／」分隔四部分：

```text
今天／我和爸爸／去公園／散步
星期一／我／在課室／上中文課
晚上／我和哥哥／在家裏／吃飯
```

逗號及句號由遊戲自動加入。匯入題庫保存在使用者自己的瀏覽器，並不會同步到 GitHub 或其他玩家。

## GitHub Pages

在專案 Settings → Pages，選擇 Deploy from a branch，以 `main` 分支及 `/ (root)` 作為來源。
